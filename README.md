# CodeAlpha_Unemployment_Analysis

This project is part of the **CodeAlpha Data Science Internship**. It involves performing Exploratory Data Analysis (EDA) on unemployment data using Python, with a key focus on analyzing trends and the impact of Covid-19.

---

## 📌 Task Description
- **Task 2:** Unemployment Analysis with Python
- **Domain:** Data Science / Data Visualization
- **Objective:** Analyze unemployment rate datasets, observe seasonal variations/trends, and evaluate the impact of the Covid-19 period on unemployment rates across regions.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Libraries Used:**
  - `pandas` - Data loading and cleaning
  - `matplotlib` & `seaborn` - Visualizations and trend plots

---

## 📊 Workflow
1. **Data Preprocessing:** Cleaned column headers, handled missing values, and converted date strings into proper pandas datetime format.
2. **Data Analysis & Visualization:** Plotted time-series trend lines using Seaborn to visualize unemployment variations over time.
3. **Output:** Generated and saved a high-resolution chart (`unemployment_trend.png`).
